# База знаний: стилистика бота Step Together

Этот документ — самодостаточное ТЗ по **стилю** для создания нового
Telegram-бота в той же эстетике, что и бот шагового марафона Step Together
(@wegrowmarathon_bot). Задания, баллы и правила нового бота описываются
отдельно заказчиком; здесь — только то, как бот должен **выглядеть, звучать и
быть устроен**, чтобы участник воспринимал его как продолжение первого.

Скопируй этот файл целиком в новый диалог как контекст.

## 1. Кто такой бот: маскот и голос

**Маскот и ведущий всех диалогов — росток Stepy 🪴.** Он не «система», а
дружелюбный проводник, который «объясняет на пальцах». Каждое сообщение
участнику — это реплика Stepy.

**Как звучит Stepy:**
- Обращение на **«ты»**, тёплое, бодрое, без официоза. Пол участника
  неизвестен — используем форму «прислал(а)», «дисквалифицирован(а)».
- Короткие предложения. Одна мысль — одна фраза. Часто в конце — мотивация:
  «Ты сможешь! 💪», «Так держать! 🔥», «Погнали к финишу! 🏁».
- Эмодзи — 1–3 на сообщение, в конце фразы, как интонация, не как украшение
  каждого слова. Любимые: 🪴 🌱 🌿 🌳 💪 🔥 ✅ 📸 ⏳ 🎉 🏆 🌙 👇 🙂 😉 💚.
- Не читает мораль. Даже отказ — мягкий: «Не расстраивайся: завтра новый день
  и новые шаги!»
- Объясняет «зачем», а не только «что»: «…чтобы в отчёт попал весь твой день,
  до последнего шага 😉».
- Метафора роста: с баллами «растение подрастает» 🪴. Стадии в приложении:
  🌱 Семечко → 🌿 Росток → 🪴 Кустик → 🌳 Дерево → 🌸 Цветение.

**Заказчик и модераторы — P&C** (People & Culture). В текстах пишется
`P&amp;C` (HTML-экранирование). Обратная связь ведёт на личный контакт
сотрудника P&C (в Step Together — https://t.me/DaryaPMI).

**Компания никогда не называется брендом** — только «наша дружная компания»
/ «наш дружный коллектив».

**Язык — только русский.** Кавычки — «ёлочки». Тире — длинное «—». Числа с
разрядами через пробел: «10 000», «12 340».

## 2. Два тона: участник и админ

| | Участнику | Админу (P&C) |
|---|---|---|
| Голос | Stepy, цитата `<blockquote>` | Деловой, без Stepy и без цитаты |
| Обращение | «ты», эмоционально | «ты», нейтрально, по делу |
| Эмодзи | 1–3, тёплые | 1 в заголовке + служебные (🧾 👤 🌳 📅 ⚠️ ✅ ❌) |
| Пример | «Красота! Сохранил твою статистику 📈» | «🧾 <b>Результат на проверку</b>» |

Админские карточки — это структурированные «досье»: заголовок жирным,
дальше строки `эмодзи <b>значение</b>` по одной на строку, в конце — призыв к
действию («Проверь скриншот и прими решение.»).

## 3. Формат сообщения (HTML, parse_mode=HTML)

Все тексты — HTML. Базовый скелет сообщения участнику:

```
<эмодзи> <b>Заголовок сообщения</b>

🪴 <b>Stepy</b>
<blockquote>Реплика Stepy: что произошло и что делать дальше 👇</blockquote>
```

Реализация в коде — хелпер, который ОБЯЗАТЕЛЬНО используется для всех реплик:

```python
STEPY = pe("🪴")   # премиум-эмодзи маскота, id 5305729158385533791

def stepy(body: str) -> str:
    """Реплика Stepy — в красивой цитате с его эмодзи."""
    return f"{STEPY} <b>Stepy</b>\n<blockquote>{body}</blockquote>"
```

Правила вёрстки:
- **Заголовок** — эмодзи + `<b>…</b>`, затем пустая строка, затем `stepy(...)`.
  Короткие ответы (ошибка ввода, «уже засчитано») — только `stepy(...)` без
  заголовка.
- **Ключевые слова жирным**: числа, названия кнопок, дедлайны, статусы:
  «до <b>23:55</b>», «жми «<b>👟 Шаги за сегодня</b>»».
- Название кнопки в тексте — всегда в «ёлочках» и с тем же эмодзи, что на
  кнопке.
- Пример ввода — отдельной цитатой: `<blockquote>Например: 12340</blockquote>`.
- Многошаговые сценарии подписываются «**Шаг 1 из 2 — …**», «**Шаг 2 из 2 — …**».
- Списки правил/пунктов нумеруются премиум-кейкапами через `num(n)`
  (`1⃣`, `2⃣`, двузначные склеиваются `1⃣1⃣`), а разделы — заголовком с эмодзи:
  «<b>🚀 Кто и как участвует</b>», «<b>🎯 Сколько баллов за день</b>».
- Пояснения к разделу — курсивом `<i>…</i>`.
- Длинные тексты (правила, помощь) начинаются с реплики Stepy «Привет! Я Stepy
  🪴 … Сохрани это сообщение.» и заканчиваются блоком «⚠️ <b>Важно:</b> …».
- Пользовательские данные всегда через `html.escape`.

## 4. Премиум-эмодзи

Бот использует кастомные (премиум) эмодзи Telegram через тег
`<tg-emoji emoji-id="…">🪴</tg-emoji>`. Работает при `parse_mode=HTML`, если
владелец бота имеет Telegram Premium; иначе — обычный эмодзи как фолбэк.

- `bot/premium_emoji.py`: `ENABLED = env PREMIUM_EMOJI=true`; `pe(emoji)` →

## 5. Шаблоны сообщений (эталоны для копирования тона)

**Приветствие**
```
🪴 <b>Привет! Я Stepy — твой проводник по марафону Step Together.</b>

🪴 Stepy
> Всё просто, объясняю на пальцах:
> 1) каждый день ходишь 🚶
> 2) присылаешь мне число шагов и скриншот 📸
> 3) P&C подтверждает — и капают баллы ⭐
> 4) с баллами растёт твоё растение 🪴
>
> Готов? Сначала быстро глянем правила 👇
```

**Шаг сценария**
```
👟 <b>Шаг 1 из 2 — количество шагов</b>

> Напиши, сколько шагов ты прошёл сегодня. Только цифры — я пойму 🙂
> Например: 12340
```

**Ошибка ввода** — коротко, без заголовка:
`> Мне нужно <b>число</b>. Напиши количество шагов цифрами, например 12340.`

**Отправлено на проверку**
```
✅ <b>Отправлено на проверку!</b>

> Твои <b>12 340</b> шагов и скриншот ушли сотруднику P&C. Как только
> результат примут — баллы засчитаются, а день в календаре станет зелёным.
> Спасибо, что двигаешься! 🪴
```

**Принято**
```
🎉 <b>Результат принят!</b>
> 12340 шагов = <b>+2</b> балл(а).
> Твоя серия: <b>4</b> дн. подряд 🔥
> Так держать — растение подрастает! 🪴
```

**Окно закрыто / не то время** — заголовок 🌙 или 📈, объяснение «почему»,
приглашение вернуться, обещание напомнить:
`> Отчёты принимаются в воскресенье <b>с 22:00 до 23:55</b>. Эта неделя уже
> закрыта — в следующее воскресенье я обязательно напомню 💚`

**Напоминание (пуш по расписанию)**
`> Эй, чемпион! 🔔 До конца дня осталось немного, а шаги ещё не сданы. Даже
> короткая прогулка перед сном — это баллы. Жми «👟 Шаги за сегодня»! 💪`

**Последний звонок**
```
⏰ <b>Последний звонок!</b>
> Ты ещё не прислал(а) еженедельный отчёт, а приём закроется в <b>23:55</b>!
> Скорее: кнопка «📈 Еженедельный отчёт» → скриншот … Одна минута — и
> неделя в зачёте 💪
```

**Анонс события** (челлендж / флешмоб): заголовок с эмодзи события, реплика
Stepy: правило одной фразой с жирным условием, затем «как участвовать»,
дедлайн жирным, мотивационный хвост 🚀.

**Дисквалификация** — заголовок ⛔, спокойный тон, куда обратиться.
**Восстановление** — ♻️ «Отличные новости — P&C вернула тебя в игру!».

**Лидерборд**
```
👑 <b>ЛИДЕРБОРД</b>
<i>Step Together · растём вместе</i>

🌟 <b>Команды</b>
🥇 Бамбук — 128
🥈 Секвойи — 117
🥉 Баобабы — 99
4. Эвкалипты — 80

👣 <b>Топ-10 участников</b>
…
> Каждый шаг двигает не только тебя, но и всю команду. Разрыв в пару баллов
> закрывается одной вечерней прогулкой 🌿
```

**Карточка админу на модерацию**
```
🧾 <b>Результат на проверку</b>
👤 <b>Иванов Иван</b> · @ivanov
🌳 Секвойи
📅 2026-07-20
👟 Шагов заявлено: <b>12340</b>

Проверь скриншот и прими решение.
```
Кнопки: `✅ Принять` `❌ Отклонить` / `⚠️ Предупреждение`.

**Рассылка-инструкция** — заголовок 📸, Stepy «Сохрани это сообщение»,
пошаговые списки с `num()`, блок «⚠️ <b>Важно, друзья:</b> …» (строго, но
объясняя «чтобы зачёт был честным для всех команд 🤝»), блок «⏰ <b>Напоминаю
про время:</b>» маркерами «•», цитата курсивом с автором, финал — Stepy
«Удачи на дистанции! … Я болею за тебя 🪴✨».

## 6. Клавиатуры и навигация

**Reply-меню участника** (`resize_keyboard=True`), подписи редактируются из
админки, у каждой кнопки — эмодзи слева:
```
[👟 Шаги за сегодня]
[📈 Еженедельный отчёт]
[📊 Мой прогресс] [🏆 Лидерборд]      ← открывают Mini App (web_app)
[📋 Правила] [❓ Помощь]
[💬 Обратная связь]
```
Главная кнопка действия — одна, на всю ширину, первой строкой.

**Inline-кнопки** — эмодзи + глагол: «✅ Подтвердить», «❌ Отклонить»,
«🚀 Запустить и оповестить», «🤫 Подготовить без пуша», «👁 Предпросмотр
пуша», «✏️ Пересоздать», «🗑 Удалить», «⬅️ Назад», «✖️ Отмена»,
«Далее ➡️». Согласие с правилами — «Принимаю правила 🏁».

**Выбор из списка** — по одной кнопке в строку (`adjust(1)`), у выбранных
`✅`, у невыбранных `▫️`, есть «🌳 Все команды / ◻️ Снять все».
Календарь дней — 4 в ряд, статус префиксом: `✅20.07` `⏳21.07` `❌22.07`
`·23.07`.

**Админ-панель** (`/admin`) — inline-сетка 2 в ряд, группами:
`🧾 Результаты · ✍️ Ручной ввод · 🗑 Отмена результата · 🎲 Тайный челлендж ·
🤝 Командный флешмоб · 📊 Активности и участие · 👥 Участники · 🌳 Команды ·
🏆 Лидерборд · 📊 Вовлечённость · 📣 Рассылка · 📥 Экспорт в Excel ·
📢 Каналы · ⚙️ Оформление`.

**Паттерн любой админ-фичи**: вход из панели → пошаговый выбор параметров
inline-кнопками (черновик в FSM) → экран «Проверь …» со сводкой → кнопки
«👁 Предпросмотр пуша / 🚀 Запустить и оповестить / 🤫 без пуша / ✖️ Отмена»
→ карточка с текущим состоянием и действиями. Всё, что уходит участникам,
админ **сначала видит в превью** ровно в том виде, как получат люди.

**Кнопка меню чата** — `MenuButtonWebApp(text="Открыть")` на Mini App.

## 7. Mini App: визуальный язык

Один файл `index.html`, vanilla JS, без сборщика, `telegram-web-app.js`.
Тёмная «стеклянная» тема со свежими акцентами:

```css
--bg:#0f1420; --bg2:#141a28; --card:#161d2c; --card2:#1c2437; --line:#28304a;
--tq:#00d1d2;    /* бирюза — основной акцент */
--vi:#7a5cff;    /* фиолетовый */
--coral:#ff7a59; --gold:#ffc65c;   /* тёплые акценты */
--text:#f4f3f7; --muted:#9b96a8;
--grad:linear-gradient(135deg,#00d1d2 0%,#7a5cff 100%);
--grad-warm:linear-gradient(135deg,#ff7a59 0%,#ffc65c 100%);
```

- Фон — тёмный + два мягких радиальных свечения (бирюза слева-сверху,
  фиолет справа-сверху).
- Карточки: градиент `card2→card`, `border:1px solid var(--line)`,
  `border-radius:20px`, `padding:18px`, появление анимацией `rise` с задержками
  `.05s/.1s/.15s`.
- Шрифт системный (`-apple-system, Segoe UI, Roboto`), заголовок 18px/800,
  подписи 12–13px `--muted`. Ключевые цифры — крупные, с градиентной заливкой
  текста (`background-clip:text`).
- Герой-блок: большой эмодзи растения (78px) с анимацией «прорастания» и
  плавным покачиванием; кольцевые прогресс-бары.
- Списки-рейтинги: медали 🥇🥈🥉 на цветных плашках, далее номера в тёмных
  квадратах; очки справа бирюзовым.
- Нижняя навигация: фиксированная, полупрозрачная с `backdrop-filter:blur`,
  6 вкладок с SVG-иконками, активная — бирюзовая с полоской-индикатором сверху.
  **Нижний отступ контента живёт на контейнере `.wrap`, не на `body`**
  (иначе последние элементы уходят под панель).
- Реплики Stepy в приложении — блок с левой бирюзовой полосой и 🪴.
- Правила/помощь — аккордеоны `<details>` с иконкой в квадрате, заголовком,
  подзаголовком и поворачивающимся шевроном.
- Safe-area через `var(--tg-safe-area-inset-*, env(safe-area-inset-*))`.
- Клиент никогда не вычисляет даты сам — только серверные поля (`is_today`,
  `future`), чтобы не ловить сдвиг таймзон.

## 8. Технический каркас (чтобы новый бот был «того же рода»)

- Python 3.11+, **aiogram 3.x**, polling, `MemoryStorage`, `DefaultBotProperties(parse_mode="HTML")`.
- PostgreSQL через asyncpg; своя схема (`CREATE SCHEMA IF NOT EXISTS …` +
  `SET search_path`); схема применяется идемпотентно на старте; миграции
  только аддитивные (`ADD COLUMN IF NOT EXISTS`).
- Структура: `bot/main.py` (роутеры, middleware, планировщик), `bot/texts.py`
  (ВСЕ тексты, ничего «зашитого» в хендлерах), `bot/keyboards.py`,
  `bot/db.py`, `bot/settings.py` (настройки из админки, кэш в памяти),
  `bot/notify.py` (рассылки батчами ≤25/сек с обработкой `TelegramRetryAfter`),
  `bot/scheduler.py` (APScheduler в процессе, таймзона проекта, каждая
  задача защищена проверкой «этап активен»), `bot/export.py` (openpyxl),
  `bot/handlers/<фича>.py` — один модуль на фичу.
- Порядок роутеров: онбординг ПЕРВЫМ (его команды выводят из любых FSM),
  затем админские, затем приём результатов последним.
- Таймзона `Asia/Tashkent`, все «сегодня» через `datetime.now(config.tz).date()`.
- Модерация через канал: карточка с фото + inline-кнопки; ответ админа в
  свободной форме запрашивается **в личке админа** (FSM-контекст под ключом
  личного чата), после — карточка в канале помечается.
- Админы: базовые из env `ADMIN_IDS` + добавляемые `/addadmin`; меню команд
  админа выставляется `set_my_commands(scope=BotCommandScopeChat)`.
- Глобальный обработчик ошибок отвечает мягко: «Ой, что-то пошло не так 🌱
  Попробуй ещё раз или напиши в «Обратную связь».»
- Дисквалификация не удаляет данные: `disqualified_at` + фильтр во всех
  зачётных запросах; middleware блокирует действия дисквалифицированных.
- Фото-подтверждения принимаются и как фото, и как файл-изображение
  (`doc:` префикс к file_id); анти-дубль по `file_unique_id`; в Excel — ссылки
  на фото через HMAC-подписанные URL веб-сервиса, токен бота в URL не попадает.
- Стандартный набор сервисных задач: ежедневный дайджест P&C (09:00), ночной
  Excel-бэкап админам (23:59), отложенные рассылки (`/broadcast` → «⏰ Отложить»,
  `/scheduled`), вечерние напоминания не сдавшим.
- Деплой: Render Blueprint (worker для бота + web для Mini App), ветка `main`.

## 9. Чек-лист «похоже на Step Together»

- [ ] Каждая реплика участнику — через `stepy()`, с 🪴 и `<blockquote>`.
- [ ] Заголовок сообщения = эмодзи + жирный текст, потом пустая строка.
- [ ] «Ты», тепло, короткие фразы, 1–3 эмодзи, мотивация в конце.
- [ ] Ключевые числа, кнопки и дедлайны — жирным; кнопки в «ёлочках» с эмодзи.
- [ ] Правила — нумерация `num()`, разделы с эмодзи, «⚠️ Важно» в конце.
- [ ] Админу — деловые карточки-досье без Stepy.
- [ ] Всё, что уходит людям, админ видит в превью и подтверждает кнопкой.
- [ ] Reply-меню: главная кнопка действия первой строкой на всю ширину.
- [ ] Премиум-эмодзи через `pe()` с фолбэком, id из таблицы выше.
- [ ] Mini App: тёмная тема, бирюза + фиолет, карточки 20px, растение-герой.
- [ ] Компания — «наша дружная компания»; модераторы — P&C; язык — русский.
